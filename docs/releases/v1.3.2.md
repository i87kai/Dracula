# Dracula v1.3.2

This release completes the public repository and distribution path begun in
v1.3.1. It does not add a new analysis engine.

## Highlights

- Rewritten README and reorganized project, CLI, installation, sandbox,
  `.draculaimg`, MCP, build, troubleshooting, and roadmap documentation.
- Reproducible Capstone and Unicorn source dependencies.
- Transactional updater with mandatory SHA-256 verification and automatic
  rollback on a failed replacement.
- Installer repair and uninstall preservation checks using isolated synthetic
  workspaces.
- One canonical Windows x64 executable in the release archive, with the
  GuestAgent, Agent x64, ManagedHost, rules, scripts, and
  public documentation required by the installed application.

See [CHANGELOG.md](../../CHANGELOG.md) for the detailed change summary and
[installation.md](../installation.md) for installation and verification steps.

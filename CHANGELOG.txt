============================================================
Dracula v1.0.2
Release: 2026-08-17
============================================================

Added
-----
- Height-responsive persistent header. The approved Dracula card now has four variants (Full, FullNoTips, Compact, Minimal) selected from the terminal HEIGHT after the width has chosen the artwork layout, so Dracula no longer requires a maximized window.
- Two-row ASCII vampire mark (Art::VampireMini) used by the Compact header on short terminals.
- Mouse wheel scrolling of the output viewport, via ENABLE_MOUSE_INPUT and MOUSE_WHEELED records read from the console input queue (three lines per notch).
- Ctrl+Home / Ctrl+End jump to the oldest / newest output.
- Scroll position indicator in the status row ("Output 13-30 / 42", plus "PageDown to follow" while detached).
- ANSI-aware hard wrapping (Text::WrapCells) so stored logical output is re-wrapped for the current output width instead of being truncated.
- ScreenModel::HeaderRows and HeaderVariant, making header sizing a pure, testable function of width and height.
- 65 additional terminal UI checks covering the width x height region matrix, height-responsive header selection, palette height adaptation, output history scrolling, scroll key mapping and resize state preservation.

Changed
-------
- Region sizing is now a strict priority order: the input row is always visible, then the output viewport keeps its preferred height (8 rows, floor 3), then the palette fits, and only then does the header claim what is left.
- The header variant is chosen from the terminal geometry alone and no longer changes when the command palette opens, so the header never moves or resizes while typing.
- The command palette viewport is now sized dynamically (8 rows preferred, 3 minimum) instead of always claiming 8 rows; the list still scrolls in whatever viewport it is given and its footer says so.
- OutputBuffer stores logical lines and renders them for the current viewport width, so a resize reflows the history rather than leaving rows sized for the previous geometry.
- The output scroll position is a logical line anchor, so it is preserved across width and height changes.
- Terminal input is configured explicitly for the interactive screen: mouse and window input on, quick-edit selection off, virtual-terminal input off, line/echo/processed input off.
- Tips and the working directory are dropped from the header before any output rows are sacrificed.

Fixed
-----
- Fixed command output being invisible unless Windows Terminal was maximized. The header claimed a fixed ~24 rows regardless of terminal height, leaving 0-4 usable output rows in an ordinary window.
- Fixed the output viewport being unscrollable: PageUp/PageDown existed but there was no wheel support and no way to inspect history, and the viewport had no visible position.
- Fixed the command palette consuming nearly every remaining row on short terminals, hiding all previous output.
- Fixed unsigned underflow risk in the scroll arithmetic by clamping at the oldest line instead of wrapping around.
- Fixed the palette causing the header to shrink and grow as suggestions appeared and disappeared.

Verified
--------
- Clean Release build (GCC 16.1.0, Ninja/Make, -O3) with no warnings or errors.
- 178 terminal UI checks and 112 analysis-core audit checks pass; test_emulate_buffer passes; CTest 3/3.
- Real non-fullscreen Windows Terminal runs at 80x24, 100x15, 100x18, 100x20, 100x25, 120x30 and 100x40: header, output and prompt all visible at every size.
- Real mouse wheel events injected into the console input queue scroll the output region while the header and prompt stay fixed, with the position indicator tracking and auto-follow resuming at the bottom.
- Live resize (XTWINOPS) from 120x45 to 90x22 and back: header degrades Full -> Compact -> Full automatically, typed input and scroll position preserved.
- MCP stdout remains pure JSON-RPC; redirected CLI output contains no ANSI escape sequences.

============================================================
Dracula v1.0.1
Release: 2026-08-17
============================================================

Added
-----
- Supplied Vampire Dracula ASCII artwork integrated as a compiled-in UI asset (src/cli/ascii_art.cpp), available to a released executable regardless of working directory.
- Central terminal layout engine (cli/text_layout) providing ANSI-aware and UTF-8-aware VisibleWidth, StripAnsi, PadLeft/PadRight, Center, Truncate, Fit, Wrap, HorizontalRule, BoxBuilder, RenderColumns, and a reusable Table renderer.
- Responsive startup card (cli/startup_card) with four layouts selected from the live terminal width: two-column (>=100), stacked (>=62), compact ASCII mark (>=44), and a minimal text fallback below that.
- Semantic output layer (cli/ui) providing Success/Warning/Error/Info messages, sections, key/value rows, mitigation states, truncation footers, and usage guidance blocks.
- Centralized console redraw primitives (Terminal::Console) for cursor movement, line clearing, screen clearing and style restoration, plus an RAII CursorGuard.
- Path resolution module (common/paths) distinguishing the working directory, the executable directory and the install/resource root; CHANGELOG.txt is now resolved through it.
- Command palette viewport with scrolling, category-ordered results, a position footer, and the selected command's usage shown inline.
- Argument completion driven entirely by command registry metadata via the new flagCompletions field (for example /emulate --policy -> bypass|realistic|neutral).
- Filesystem completion popup using the same interaction model as the slash palette, with directory listing, '..' segments, drive paths and automatic quoting for paths containing spaces.
- /strings --all option and "Showing N of M" footers for long output.
- Ctrl+L clears the screen while preserving the current input.
- Dedicated terminal UI regression suite (tests/test_terminal_ui.cpp, CTest target TerminalUi) verifying measurement, box geometry, responsive layouts, artwork integrity, palette state transitions, completion, session reuse and version consistency at 40/50/60/80/100/120/160/200 columns.

Changed
-------
- Startup presentation redesigned around the Vampire artwork with a two-column information block (version, build, engines, working directory) and a tips footer.
- Dracula colour palette reworked to a darker, restrained 256-colour theme with new semantic roles: Title, Primary, Secondary, Accent, Technical, Text, Muted, Success, Warning, Error, Info, Selection, Border.
- /help redesigned: commands grouped by category in a deliberate order (Analysis, Inspection, Emulation, Session, System) with descriptions aligned across all groups.
- /help <command> now renders description, usage, aliases, arguments and examples generated from registry metadata.
- Analysis output for /headers, /security, /imports, /exports, /strings, /entropy, /functions, /xrefs, /findings, /session, /emulate and /disasm rebuilt on the shared section, key/value and table renderers.
- Missing arguments now render as guidance (reason, usage, example, tip) instead of a bare red error line; red is reserved for genuine failures.
- /clear now clears the viewport and redraws a compact header while preserving the active analysis session and command history.
- Prompt restyled and always terminated with a reset so console styling can never leak.
- Command palette suggestions are ordered by category rank then name.
- Version is now generated from the CMakeLists.txt project() declaration into include/common/version.h via version.h.in; the checked-in copy was removed so there is exactly one source of truth.

Fixed
-----
- Fixed the broken startup banner border: padding was computed from std::string::size(), which counts UTF-8 bytes and ANSI escape bytes, so every line containing a bullet or colour code pushed the right-hand border out of alignment.
- Fixed misplaced right-side vertical bars and uneven padding by generating every border through the single BoxBuilder implementation.
- Fixed box width arithmetic that mixed outer width, inner width and padding inconsistently between the top rule, body rows and bottom rule.
- Fixed the line editor cursor landing one column to the right of its true position after every redraw (an off-by-one in the cursor-forward escape).
- Fixed palette artifacts caused by ad-hoc cursor escapes scattered through the line editor; redraw is now deterministic and erases exactly the rows it drew.
- Fixed long input corrupting the prompt line by adding horizontal scrolling instead of allowing terminal wrapping.
- Fixed interactive editing being disabled entirely under --no-color (the editor previously fell back to plain getline whenever colour was off).
- Fixed the cursor being left hidden or the console left styled after Ctrl+C, Ctrl+D, exceptions or exit.
- Fixed CHANGELOG.txt lookup depending on the current working directory, which failed when Dracula.exe was launched from outside the build tree.
- Fixed --mcp initializing the terminal at all; MCP stdio output is now guaranteed free of terminal setup, colour and artwork.

Verified
--------
- Clean Release build (GCC 16.1.0, Ninja, -O3) of DraculaCore, Dracula.exe, GuestAgent.exe, Capstone, test_dracula_suite.exe, test_emulate_buffer.exe and test_terminal_ui.exe with no warnings or errors.
- Terminal UI suite and the full analysis-core audit suite pass with zero failures.
- --version, --help and --analyze output verified to contain no ANSI escape sequences when redirected to a file.
- --mcp stdout verified to remain pure JSON-RPC.

============================================================
Dracula v1.0.0
Release: 2026-08-17
============================================================

Added
-----
- Unified Dracula.exe primary executable with interactive and scripted CLI interfaces.
- Capstone 5.0.1 x86/x64 disassembler engine with colored syntax highlighting.
- Control Flow Graph (CFG) analyzer with basic block discovery and ASCII topology rendering.
- Cross Reference (XRef) analyzer detecting code calls, conditional jumps, imports, and data references.
- Safe bounds-checked PE32/PE32+ parser auditing headers, sections, imports, exports, TLS, and digital signatures.
- Unicorn 2 CPU instruction emulator with configurable anti-debug policies (Bypass, Realistic, Neutral).
- Synthetic Win32 HLE subsystem with mock TEB/PEB layout and memory allocation interception.
- Native Model Context Protocol (MCP) stdio server (protocol version 2024-11-05) for AI tool calling.
- Real-time interactive line editor with cursor manipulation, Home/End, Delete/Backspace, and line clearing shortcuts.
- Interactive slash command palette (triggered by '/') with live prefix filtering and aligned descriptions.
- Keyboard navigation in command palette (Up/Down arrow selection, Tab completion, Enter acceptance, Escape dismissal).
- Intelligent autocompletion for slash commands, command-specific arguments (e.g. json, md, txt), and filesystem paths.
- Persistent command history stored across sessions with bounded size in application data directory.
- Centralized command registry (CommandRegistry) defining command metadata, aliases, categories, and handlers from a single authoritative source.
- Centralized terminal theme and capability engine (Terminal) supporting semantic color roles, width detection, and --no-color/NO_COLOR support.
- Safe ASCII fallback rendering for non-Unicode environments to eliminate terminal mojibake.
- Multi-format report serializer for machine-readable JSON, Markdown documentation, and plain text summaries.
- Dedicated /changelog command and --changelog CLI argument dynamically parsing project release history.
- Dedicated /version command and --version CLI argument displaying version, architecture, and engine metadata.
- Comprehensive 100% automated test suite verifying all intelligence engines, schemas, and UI logic.

Changed
-------
- Standardized project version baseline to Dracula v1.0.0 via centralized version.h header.
- Replaced basic std::getline REPL with custom interactive LineEditor supporting VT processing.
- Replaced legacy giant ASCII art banner with compact, professional Dracula-themed framed header.
- Unified CLI argument dispatch and interactive shell execution behind shared CommandRegistry handlers.
- Refactored JSON export to query authoritative version constants dynamically.

Fixed
-----
- Fixed Windows Terminal / console encoding mojibake by configuring UTF-8 code pages (CP_UTF8) and enabling virtual terminal processing (ENABLE_VIRTUAL_TERMINAL_PROCESSING).
- Fixed prompt character glyph corruption by providing automatic ASCII fallback ('>' instead of Unicode '❯').
- Fixed MCP mode stdout pollution by ensuring stdio JSON-RPC streams remain clean of UI banners and ANSI codes.
- Fixed output redirection emitting ANSI escape sequences when piped to files or non-interactive streams.

Verified
--------
- Capstone 5.0.1 instruction disassembly across 32-bit and 64-bit binaries.
- CFG recursive block traversal and jump target resolution.
- XRef CALL and JMP reference detection across code sections.
- Unicorn 2 Win32 HLE machine code execution with synthetic TEB/PEB.
- Anti-debug BeingDebugged policy toggles (Bypass, Realistic, Neutral).
- Safe PE parser resistance against malformed and truncated buffers.
- Deterministic 0-100 multi-signal threat evaluation and MITRE ATT&CK extraction.
- 100% syntactically valid JSON serialization and schema headers.
- MCP protocol initialize, ping, tools/list, and tools/call execution.
- Command registry registration, alias lookup, and prefix filtering.
- Line editor buffer manipulation, slash palette selection model, and history persistence.
